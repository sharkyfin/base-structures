# Базовые структуры

ЛР-1, C++17. Основа перенесена из `search-and-data`; вторая лаба не изменяется.

- AVL: вставка, поиск, удаление, шесть обходов в глубину и обход по уровням, `Map`, `Where`, `Reduce`, слияние, поддеревья и пути.
- n-арное дерево: `n` задаётся в конструкторе, четыре обхода в глубину и обход по уровням, `Map`, `Where`, `Reduce`, слияние, поддеревья и пути.
- Множество на AVL: операции над множествами, включение, равенство, функциональные операции и операторы.
- Очередь на AVL или куче: повторы и равные приоритеты, диапазоны, поиск подпоследовательности, слияние и разделение.
- Отдельная бинарная куча на своём массиве: базовые операции и линейное построение.

Деревья, множество и очередь сохраняются как значения через пробелы: `1 2 3 4 5 6`. При чтении значения добавляются обычной вставкой; точная форма исходного дерева не сохраняется. n-арное дерево записывается и заполняется по уровням. Пустая строка даёт пустую коллекцию. Значения с пробелами, кавычками и пустые строки заключаются в кавычки; это позволяет сохранять строки и записи целиком. Повторы в очереди и n-арном дереве сохраняются.

`NaryTree<T>(n)` хранит до `n` детей в каждом узле (`n >= 1`). `Add` заполняет свободные места по уровням, `AddChild` добавляет ребёнка по пути к родителю. Путь — последовательность номеров детей от 0; пустой путь обозначает корень. Удаление удаляет узел вместе с потомками, номера следующих детей сдвигаются. Поиск и извлечение по значению выбирают первое совпадение в КЛП. `Map` сохраняет форму; `Where` и `Merge` добавляют значения по уровням. Дерево не сортирует значения: поиск требует `==` и занимает O(N). Вставка по уровням амортизированно O(1); после адресного изменения или копирования очередь вставки восстанавливается обходом.

`IStorage<T>` задаёт размер и перебор, `IPriorityStorage<T>` добавляет операции с приоритетом. `PriorityQueue<T>` владеет хранилищем через `UniquePtr`; компаратор принадлежит хранилищу. По умолчанию используется AVL, явно выбрать можно так:

```cpp
PriorityQueue<int> treeQueue(MakeUnique<TreePriorityStorage<int>>());
PriorityQueue<int> heapQueue(MakeUnique<HeapPriorityStorage<int>>());
```

Копирование и функциональные операции сохраняют хранилище и компаратор. `Clone` создаёт независимую копию, `CreateEmpty` — пустое хранилище с той же политикой приоритета. Перебор обоих хранилищ идёт по убыванию приоритета и возвращает ссылки на исходные элементы. Для кучи он подготавливает отсортированный список указателей за O(N log N) и O(N) памяти; вставка и извлечение остаются O(log N), вершина — O(1). У AVL вершина — O(log N), обход — O(N).

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
ctest --test-dir build --output-on-failure
./build/structures
```

При запуске открывается меню. Демонстрация — пункт 9. Консоль работает с целыми и вещественными числами, строками, комплексными числами, студентами, преподавателями и указателями на функции. Ручной ввод и генерация с seed доступны в меню. n-арное дерево — пункт 5 после выбора типа; у очереди выбирается AVL или куча. У записей AVL сравнивает ID, очередь — оценку студента или стаж преподавателя. Для функций используются имена `square`, `negate`, `increment`. При первой сборке тестов CMake загружает GoogleTest; сборка без тестов — `-DBUILD_TESTING=OFF`.

Бенчмарк — пункт 8 в меню. Он выводит таблицу в консоль, без файлов. Для обычного прогона укажи максимальный размер `1000000` и лимит `1` секунду; для крупного — например, `10000000` и `2` секунды.

Размеры: 10 000, 100 000, 1 000 000, 10 000 000, 100 000 000. Порядки: Ascending, Descending, Random. `N` — размер входа в серию, `Операций` — фактически выполненное число вызовов; для операций над множествами это один полный вызов. `limit` отмечает достижение лимита. Он проверяется между пакетами операций, отдельный вызов не прерывается. Размеры 10⁷–10⁸ запускаются явно при достаточной памяти. Графики из исходного условия не входят в текущую консольную версию.

Для n-арного дерева бенчмарк использует `n=3`: вставка, полный поиск отсутствующего значения, обход и удаление последнего добавленного листа. Поиск и удаление замеряются по одному вызову из-за линейного поиска.

`QueueAVL` и `QueueHeap` сравнивают одинаковые операции очереди на двух хранилищах.

Владение — через свой `UniquePtr`. Копирование структур глубокое. Перечислитель возвращает ссылки на исходные элементы; коллекция должна жить дольше него и оставаться неизменной. Изменение дерева инвалидирует его перечислители. Порядок равных приоритетов очереди не фиксирован. `Map` AVL и множества объединяет эквивалентные результаты; очередь и n-арное дерево сохраняют повторы. `Reduce` вызывает `f(элемент, аккумулятор)`.

Собственный массив требует конструируемые по умолчанию и присваиваемые элементы; хранилища очереди — копируемые элементы и компаратор для клонирования. Компаратор задаёт строгий слабый порядок, для точного поиска в очереди и куче требуется `==`. Строковые преобразования нестандартных типов передаются функциями.

```sh
cmake -S . -B build-sanitizers -DCMAKE_BUILD_TYPE=Debug -DENABLE_SANITIZERS=ON
cmake --build build-sanitizers -j 2
ctest --test-dir build-sanitizers --output-on-failure
./build-sanitizers/structures
leaks --atExit -- ./build/structures
```
