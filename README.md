# Базовые структуры

ЛР-1 на C++17: собственные контейнеры, консольное меню, визуализация AVL и бенчмарки с PNG-графиками.

## Реализованные структуры

N — число элементов; оценки времени приведены для операций с одним элементом, если не указано другое.

| Структура | Сложность основных операций |
| --- | --- |
| AVL-дерево, множество и словарь на AVL | Вставка, поиск, удаление — O(log N); полный обход — O(N) |
| Бинарная куча | Добавление — O(log N) амортизированно; извлечение вершины — O(log N); вершина — O(1); построение из коллекции — O(N); поиск и удаление по значению — O(N) |
| Очередь на AVL | Добавление, извлечение и просмотр вершины — O(log N); упорядоченный перебор — O(N) |
| Очередь на куче | Добавление — O(log N) амортизированно; извлечение — O(log N); вершина — O(1); упорядоченный перебор — O(N log N) |
| Отсортированная последовательность и словарь на массиве | Поиск — O(log N); вставка и удаление — O(N) |
| Хеш-таблица с цепочками | Поиск — O(1) в среднем; вставка и удаление — O(1) в среднем амортизированно; худший случай — O(N) |
| Динамический массив | Доступ по индексу — O(1); добавление в конец — O(1) амортизированно; вставка и удаление внутри — O(N) |
| Односвязный список | Добавление в начало/конец и удаление первого элемента — O(1); поиск и удаление по значению — O(N) |

У кучи отдельная вставка при расширении массива может занимать O(N). Объединение, пересечение и разность двух AVL-множеств по N элементов в этой реализации — O(N log N).

Также есть `Map`, `Where`, `Reduce`, семь обходов дерева, поддеревья, операции над множествами и сохранение в строку. Очередь сохраняет повторы. Владение памятью — через свой `UniquePtr`, копирование контейнеров глубокое.

## Сборка и запуск

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DENABLE_SANITIZERS=OFF
cmake --build build -j 4
ctest --test-dir build --output-on-failure
./build/structures
```

В меню: **8 — бенчмарк, 9 — демонстрация**. Визуализация AVL: `./build/GUI/avl_visualizer`, затем открыть http://127.0.0.1:8080. При первой сборке CMake загружает GoogleTest, cpp-httplib и pbPlots; далее программа работает без интернета.

## Бенчмарки

28 размеров от 1 000 до 1 000 000 элементов, три порядка входа: возрастающий, убывающий и случайный. Один прогрев, затем среднее арифметическое семи замеров; seed — 42. Генерация данных и проверки выполняются вне таймера, лимита времени нет. PNG строятся на C++ через pbPlots.

```sh
./build/structures_benchmark
# Перестроить графики из готовых средних без повторных замеров:
./build/structures_benchmark --plot benchmark/results < benchmark/results/summary.csv
```

### Замеры при N = 1 000 000

Случайный порядок, Release, среднее семи замеров. Вставка и удаление/извлечение измеряются для **всех N элементов**, просмотр вершины и поиск — на **один запрос** из пакета 100 000 запросов. Времена относятся к этому прогону.

| Структура | N вставок, мс | N удалений/извлечений, мс | Просмотр вершины, нс/запрос |
| --- | ---: | ---: | ---: |
| AVL-дерево | 896.28 | 1042.14 | — |
| Множество на AVL | 990.34 | 956.28 | — |
| Очередь на AVL | 903.55 | 474.51 | 13.89 |
| Очередь на куче | 22.16 | 200.64 | 3.04 |
| Бинарная куча | 16.88 | 184.70 | 2.02 |

| Поиск | Ключ найден, нс/запрос | Ключ отсутствует, нс/запрос |
| --- | ---: | ---: |
| AVL-дерево | 683.06 | 752.14 |
| Множество на AVL | 674.92 | 688.98 |

- Полный обход AVL: ЛКП — **246.45 мс**, по уровням — **255.16 мс**.
- Два множества по N элементов с пересечением N/2: объединение — **1084.41 мс**, пересечение — **480.67 мс**, разность — **446.02 мс**.
- Построение кучи из готовой коллекции — **15.64 мс**.

Все средние: [summary.csv](benchmark/results/summary.csv). Все 13 PNG-графиков: [index.html](benchmark/results/index.html). Отдельные замеры и параметры в дополнительные файлы не сохраняются.

## Выводы

- AVL сохраняет логарифмическую высоту даже при отсортированном входе и подходит для поиска и упорядоченного хранения.
- Для приоритетной очереди куча оказалась быстрее AVL: в указанном прогоне заполнение быстрее в **40.8 раза**, извлечение — в **2.4 раза**.
- Построение кучи снизу вверх имеет оценку O(N). При возрастающем входе оно заняло **9.86 мс** против **24.88 мс** для N вставок; при случайном входе разница меньше — **15.64 против 16.88 мс**. Практический выигрыш зависит от порядка данных.
